# Hospital-Readmission-Analysis

## Overview
This project explores patient readmission patterns across a national hospital chain to identify key factors influencing 30-day readmission rates. By analyzing 10,000 patient records with over 50 variables, this project aims to help hospital executives make data-driven decisions that reduce readmissions, improve patient outcomes, and minimize CMS penalties.

## Business Question
What demographic, medical, and hospital-related factors most strongly predict patient readmissions within 30 days?

## Analysis
### 1. Regional Analysis
The filled map that focuses on regional trends. This map shades each state by its readmission rate. Darker hues indicate a larger gap from the average, helping hotspots stand out at a glance. When viewers adjust the Gender or Age Group filters, the colors recompute for that segment, revealing whether specific populations drive a state’s performance. This view addresses the “where” question and directs leaders to regions that warrant a closer examination of discharge processes, care coordination, or post-acute networks. <img width="686" height="619" alt="Screenshot 2025-10-18 at 3 07 11 AM" src="https://github.com/user-attachments/assets/a0125c85-1b5d-4ec4-a4ed-ad920d96bb82" />

### 2. Demographic Analysis
The heatmap focuses on demographic trends. Each cell in the grid displays the readmission rate for a specific age group and gender combination, with color intensity and data labels indicating the level of risk. Scanning across columns exposes age-related patterns, and moving down rows shows differences by gender. Because it recalculates with the dashboard filters, leaders can test hypotheses (e.g., whether older cohorts consistently run higher in certain states or under specific pathways).
